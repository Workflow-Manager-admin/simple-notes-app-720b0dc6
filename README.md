**Notes Frontend Mobile App**

A modern, minimalistic Kotlin Android app using Jetpack Compose and Material 3. Features:

- View scrollable list of notes (main screen)
- Floating action button to add new note
- View note details with edit/delete actions
- Create, edit, and delete notes, all using Supabase backend
- Light theme, primary color: #2196F3, secondary: #1976D2, accent: #FFEB3B
- Architecture: Compose, ViewModel, navigation, minimal dependencies
- Ready to connect to Supabase via SUPABASE_URL and SUPABASE_KEY env variables; see BuildConfig usage in code.

Place your Supabase URL and KEY in the appropriate environment/config for Android builds (see code comments).
